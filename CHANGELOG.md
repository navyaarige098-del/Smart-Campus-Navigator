# Changelog

## [1.0.0] – 2026-11-10
### Added
- Directory of 18 campus places in 7 categories (departments, classrooms, labs, libraries, offices, halls, facilities)
- Search by name, room number or keyword, with category filter chips
- Offline campus map drawn with CustomPainter; zoom, pan and tap a building
- Shortest walking route with Dijkstra's algorithm: distance, walking time, step-by-step directions
- Place details screen with building, floor, room and timings
- Saved places and last 5 recently viewed places stored with shared_preferences
- Light and dark themes
- Unit and widget tests, GitHub Actions CI
